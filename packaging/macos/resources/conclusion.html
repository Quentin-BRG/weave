Weave is installed

The installation self-check ran as part of this install, so there is nothing left to set up. Open a new terminal and start collaborating:

cd my-project
weave host

Weave checks the repository itself before starting, prints an invite, and publishes a Cloudflare Quick Tunnel using the bundled cloudflared. Share the invite over a channel you trust — it grants full read and write access to the session.

Someone joining a session runs:

cd my-project
weave join

If anything ever looks wrong, weave doctor is the troubleshooting command. You do not need to run it as a setup step.
