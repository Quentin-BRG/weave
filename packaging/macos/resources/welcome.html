Weave

A lightweight real-time collaboration layer above Git. This installs the weave command line tool and everything it needs.

Installed into:

  • /usr/local/bin/weave — the universal binary, Apple silicon and Intel
  • /usr/local/libexec/weave/ — the bundled cloudflared and its licences

You do not need Rust, and you do not need to install cloudflared separately: this package contains it.

This package is not signed and not notarized. It carries no Apple Developer ID. macOS Gatekeeper will say so, and opening it may require Control-clicking the file and choosing Open, or allowing it under System Settings → Privacy & Security. Verify the download against the SHA256SUMS published with the release if that matters to you.

Git must be installed. xcode-select --install provides it if you do not have it yet.
